# 对话历史

## 我想开发一个博客网站
我有这样一个想法，我想开发一个博客网站，在网站的首页是一个类似个人简历的自我介绍，包含我的项目经历，工作经历，作品集等等。
然后再顶部有一些Menu，可以切换到不同的文章集合中，比如每月总结，后端开发等等。

我的想法是，一切都是基于Markdown的，无论是首页还是其他博客文章。我理想的工作流是这样的：
1. 我写一份Markdown文章
2. 然后使用 git push
3. 然后GitHub自动构建，并发布最新的博客文章

如果可能，我希望建立一个目录就相当于建立了一个文件集，这个目录就会在顶部的Menu中展示出来，而且**支持嵌套**。
